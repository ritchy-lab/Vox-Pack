# Captures d'écran

Elles sont affichées dans les trois README (français, anglais, allemand).

| fichier | ce que ça montre | où c'est utilisé |
|---|---|---|
| `fenetre-v2-fr.png` | la fenêtre principale, en français | README.md |
| `fenetre-v2-en.png` | la fenêtre principale, en anglais | README.en.md |
| `fenetre-v2-de.png` | la fenêtre principale, en allemand | README.de.md |
| `voix-pretes-v2-fr.png` | le message de fin de génération | README.md |
| `voix-pretes-v2-en.png` | le même, en anglais | README.en.md |
| `voix-pretes-v2-de.png` | le même, en allemand | README.de.md |
| `aide-v2-fr.png` | la fenêtre d'aide | README.md |
| `aide-v2-en.png` | la même, en anglais | README.en.md |
| `aide-v2-de.png` | la même, en allemand | README.de.md |

Le dossier `langues/` contient les quinze captures de la galerie
(`docs/langues-galerie.md`), une par langue.

Le dossier `non-utilisees/` contient les autres captures (alertes, cas
d'erreur…). Il est **exclu du dépôt** (voir `.gitignore`) : ces images restent
sur le Mac, elles ne sont pas envoyées sur GitHub — 2,9 Mo que personne ne
verrait.

**Taille** : les fenêtres sont ramenées à 1400 px de large (elles étaient en
2x, pour les écrans Retina). C'est assez net et deux fois plus léger.
