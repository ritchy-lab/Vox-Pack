# Cartes de visite du dépôt

Ces images sont des propositions pour l'**aperçu de lien** : l'image que GitHub
affiche quand on colle l'adresse du dépôt sur un forum, dans un Discord ou sur
un réseau social. Elle ne s'affiche **pas** sur la page du dépôt elle-même.

| fichier | disposition | langue |
|---|---|---|
| `carte-visite-A-francais.png` | logo centré, texte dessous | français |
| `carte-visite-A-anglais.png` | logo centré, texte dessous | anglais |
| `carte-visite-B-francais.png` | logo à gauche, texte à droite | français |
| `carte-visite-B-anglais.png` | logo à gauche, texte à droite | anglais |

**Comment l'installer** : GitHub → le dépôt → Settings → *Social preview* →
Edit → Upload an image. (1280 × 640, moins de 1 Mo : les quatre conviennent.)

**Rien n'est définitif** : on peut changer d'image autant de fois qu'on veut, et
en garder une différente pour le forum francophone et pour le Discord anglais.
